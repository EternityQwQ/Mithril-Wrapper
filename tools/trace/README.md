# Host symbol trace

Host traces record only symbol lookup order, renderer lifecycle stage, host
revision and platform metadata. Account names, access tokens, paths containing
user names, shader/resource contents and world data are prohibited.

The initial artifact intentionally has no fabricated events because an exact
Amethyst-iOS/LWJGL revision has not been supplied. Until a real Minecraft
1.21.1 trace is captured, matching ABI entries remain `provisional`.
